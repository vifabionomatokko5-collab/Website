# 🌵 Miragem SMP - Website Oficial

Site oficial do servidor Minecraft **Miragem SMP**.

![Miragem SMP Banner](https://via.placeholder.com/1200x400/ff6b00/fff?text=Miragem+SMP)

## 📋 Sobre o Servidor

O **Miragem SMP** é um servidor Survival com uma comunidade ativa e amigável! Com eventos semanais, ranks exclusivos e uma loja integrada, você vai se divertir como nunca!

### 🔰 Modo de Jogo
- **Survival** com proteção contra griefing
- Eventos semanais com premiações
- Ranks exclusivos com perks incríveis
- Suporte para **Java** e **Bedrock** (Geyser)

### 🎮 Versão
- **Java:** 1.21.11
- **Bedrock:** 1.21.11 (via Geyser)

### 🌐 Como Entrar

## 🛠️ Tecnologias Utilizadas

- **Backend:** Node.js + Express
- **Frontend:** HTML + CSS + EJS
- **Hospedagem:** Render

## 📂 Estrutura do Projeto

```
miragem-site/
├── index.js              # Servidor Express
├── package.json          # Dependências
├── views/
│   └── index.ejs         # Página principal
├── public/
│   ├── css/
│   │   └── style.css     # Estilos
│   └── images/           # Imagens
└── render.yaml           # Configuração do Render
```

## 🚀 Como Rodar Localmente

1. Clone o repositório:
```bash
git clone git@github.com:vifabionomatokko5-collab/miragem-smp-site.git
cd miragem-smp-site
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor:
```bash
node index.js
```

4. Acesse no navegador:
```
http://localhost:3000
```
